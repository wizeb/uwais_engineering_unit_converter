# Engineering Unit Converter

## What It Does

This program converts various engineering units, including length, temperature, weight, and speed.

## How to Run It

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the Python file.
4. Run the program using the Run Python File button.

## Sample Output

```text
ENGINEERING UNIT CONVERTER

LENGTH CONVERSION
Millimeters to Inches

Enter measurement: 100
Enter decimal places: 4

Result: 3.9370 inches
```

## My Own Twist

Decimal Precision Control allows users to choose the number of decimal places they want displayed in their conversion results.
